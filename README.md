# Universal QA Skills

Technology-agnostic AI quality engineering skills with multi-agent orchestration.

This repository distributes 15 specialist skills through `npx skills`. QA orchestration roles and report templates are included inside the `qa-orchestrator` skill.

## Install

```bash
npx skills add truongnat/universal-qa-skills
```

To select all skills with a supported coding agent:

```bash
npx skills add truongnat/universal-qa-skills --skill '*' -y
```

Subagent spawning requires delegation support in your coding agent. Installing skills does not register native agents automatically.
