# Universal QA Lead Prompt

Use the `qa-orchestrator` skill, read its bundled `agents/qa-lead.md` and `workflows/multi-agent-protocol.md`, analyze the project and risks, dispatch relevant specialist roles via real host-native subagent tooling if available, collect observed evidence, challenge serious findings, and deliver a traceable QA report with release readiness. **Present the final report using markdown tables, sections, and bullet lists** per `references/report-output-format.md` (execution matrix, defect table, release gates)—not a single unstructured paragraph. If native spawning is unavailable, execute sequentially and disclose it. Do not modify source or production data.
